Gamedex

Un catalogue de jeux vidéo bâti sur l'API RAWG : recherche, filtres par plateforme et par boutique, tri, défilement infini, fiches détaillées et favoris qui survivent au rechargement.

  • Lire le code

Une vraie application, pas une démonstration.

Cinq routes réelles : la liste des jeux avec recherche, filtres et défilement infini ; la fiche d'un jeu avec sa description, sa bande-annonce, ses succès et leur taux de déblocage, ses studios et éditeurs ; tous les jeux d'un éditeur ; les favoris ; et une page d'erreur qui ramène quelque part.

Les favoris tiennent dans un contexte React adossé au stockage local : l'état persiste sans serveur. La clé d'API vit dans un fichier d'environnement jamais versionné : elle n'apparaît nulle part dans le code source.

Projet réalisé en binôme avec Antoine Delebecque, dans le cadre du module 2WEBD. Vérification de types, analyse statique et un parcours de bout en bout sous Cypress font partie des scripts du dépôt.
