Éclosion

Une expérience web 3D où le défilement est le temps : huit actes, du Néant à l'Aube. Cent pour cent procédurale, aucun modèle ni texture ni fichier audio.

  • Charge de première visite réduite de 19 %, gel de 617 ms éliminé
  • Zéro render React à 60 images par seconde, un seul registre d'uniforms
  • Repli complet sans WebGL, rendu côté serveur, bilingue
  • Next.js
  • React Three Fiber
  • GLSL
  • TypeScript
  • WebAudio
