DataSentinel

A dashboard that replaced the manual tracking of digital-product security, and the full-stack extensions that make it usable day to day.

From spreadsheets to a single source.

Security tracking for digital products lived in hand-maintained spreadsheets: vulnerability status, compliance, penetration-test progress. Every cross-check was copy work, and nobody held the same version of the number.

DataSentinel centralises that monitoring in a Looker dashboard wired straight to the data. The number on screen is the number at the source; there is no intermediate version left to maintain.

What I built

Delivery

The modelling

Working the data through Google Cloud Platform and BigQuery: complex SQL queries and modelling in LookML. This is the layer that decides what an indicator means: the place where a vague definition costs the most.

The full-stack extensions

A dashboard shows; it does not let you act. I built extensions embedded in Looker (Python backend, React frontend) to make penetration-test management interactive: consult, update and follow up inside the tool rather than beside it.

The deployment

A continuous integration and delivery pipeline, and infrastructure described as code: Terraform, GitHub Actions, Docker, Kubernetes. The tool redeploys without a manual step.

What I took away

The Google Looker and LookML certifications, and one conviction: on a security subject, the value is not in the chart but in the definition of the data it displays.

Confidentiality
